Articulated Reverse
Parking with NMPC

Reversing a tractor towing an unsteered passive trolley is an unstable articulated system — analogous to balancing a fast inverted pendulum on wheels. By augmenting a Frenet-frame NMPC formulation with trailer kinematics and soft barrier functions, precise reverse docking is achieved without jackknifing.

the problem: articulated instability

Simply put, reversing a tractor with a passive trolley is a notoriously difficult control problem because the articulated mechanical linkage creates an inherently unstable system. Any small angular deviation between the tractor and the trailer rapidly amplifies when driving backwards, leading directly to a jackknife event where the hitch locks up and control authority is completely lost.

When starting this project, our baseline was an existing Model Predictive Controller (MPC) formulated in a Frenet Frame, implemented using CasADi and solved via the high-speed Fatrop solver. However, the state vector of that baseline MPC contained only the tractor states. The controller had zero awareness of where the trailer was, what angle it was oriented at, or how steering inputs would propagate through the hitch joint.

augmenting state space & kinematics

To achieve full authority over the articulated trailer, I augmented the NMPC state with the trailer's own position and heading relative to the reference path, along with the non-holonomic hitch kinematics that couple the tractor to the trolley. The controller now knows where the trailer is, which way it points, and how a steering input will propagate through the hitch.

Why include the trailer's path deviations in the state space?
By making the trailer's longitudinal and lateral deviations from the path explicit, the NMPC can regulate them directly. The optimization drives both towards zero, so the back of the trolley precisely follows the desired path while reversing, rather than just the tractor following the path and dragging the trailer off-course.

multi-stage objective & soft jackknife barrier

Without constraining the trailer variables in the cost function, the articulated joint remains unconstrained. I formulated a multi-stage objective that balances tractor path tracking, trailer tracking, control effort, actuator smoothness, and a steep nonlinear barrier against jackknife limits.

The soft jackknife barrier is a high-order penalty on the articulation angle between tractor and trailer. Hard constraints on that angle often cause interior-point and SQP solvers to fail with infeasibility spikes during aggressive reverse maneuvers, so the barrier acts as a differentiable repulsive wall instead. It stays negligible in normal driving and ramps up sharply just before the physical jackknife limit is reached.

core mpc techniques implemented

Deploying a 6D non-holonomic articulated NMPC onto real hardware required rigorous algorithmic optimization in CasADi and Acados to guarantee real-time execution bounds:

Move Blocking

To maintain a long prediction horizon for anticipating reverse path curvature without blowing up computational complexity, control inputs are held constant across blocks of future intervals. This dramatically reduces the number of decision variables in the quadratic subproblem.

Warm Starting

Nonlinear optimization algorithms require good initial guesses. At every control tick, the solver is seeded with the shifted optimal state and control trajectories from the previous step. This warm starting enables the Acados SQP solver to converge to numerical tolerances in just 1–2 iterations.

Geometric Projection

Rather than introducing additional differential equations for every trailer variable, which increases integration error and solver burden, the trailer's path deviations are calculated via direct geometric projection inside the objective, keeping the state representation minimal while enforcing accuracy.

system integration & real bot deployment

Once the controller demonstrated robust performance in simulation, the next challenge was taking it to physical robot hardware. In the real world, how do we acquire accurate, high-rate pose estimates of an unsteered, unpowered trolley?

One of my teammates developed a real-time trolley pose estimation algorithm utilizing high-intensity reflective tapes tracked via onboard LiDAR. I took ownership of the System Integration: wiring the live LiDAR pose estimation pipeline directly into our CasADi/Acados NMPC control loop via ROS2/Python interfaces, handling clock synchronization, latency compensation, and state filtering.

The integrated system successfully demonstrated smooth, autonomous reverse parking on the physical articulated robot, smoothly backing the trolley into narrow loading bays without human intervention or jackknife faults.
